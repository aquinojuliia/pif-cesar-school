|Item| Instrução          | Status          | Justificativa                                                                                                     |
| ---| ------------------ | --------------- | ----------------------------------------------------------------------------------------------------------------- |
| a) | `int a;`           | Correto   | Declara a variável `a` como `int`, que é um tipo válido em C.                                                           |
| b) | `float b;`         | Correto   | Declara `b` como número de ponto flutuante de precisão simples.                                                         |
| c) | `double float c;`  | Incorreto | `double float` não é uma combinação válida para declaração de variável em C. O correto seria `double c;` ou `float c;`. |
| d) | `unsigned char d;` | Correto   | Declara `d` como `char` sem sinal, permitindo apenas valores não negativos.                                             |
| e) | `unsigned e;`      | Correto   | `unsigned` sozinho é permitido em C e equivale a `unsigned int`.                                                        |
| f) | `long float f;`    | Incorreto | `long float` não é um tipo válido em C. Para maior precisão, utiliza-se `long double`.                                  |
| g) | `long g;`          | Correto   | Declara `g` como `long int`; quando `int` é omitido, ele é considerado implicitamente.                                  |
| h) | `long double h;`   | Correto   | `long double` é um tipo válido para números de ponto flutuante com maior precisão.                                      |
